A tiny agent-built garden game, day one vs day seven: the same map, the same start, filmed a week apart after daily updates — one sprout and one coin on day one; flowers, butterflies, coins and a friend by day seven. main.ts copies VIDEO.json (the TikTok video of the game) to /output for make.fun's gate.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
